# Pet Care Management System

A Java-based console application for managing pet care services. This project helps pet owners register their pets and manage services such as vaccinations, grooming, and boarding.

## Features

The system includes the following options:

1. Register Pet Owner
2. Register Pet Profile
3. Book Pet Service
4. Record Vaccination Details
5. Manage Grooming Service
6. Manage Pet Boarding
7. Search Pet Record
8. Update Pet Information
9. Generate Service Report
10. Save Records to File
11. Exit Application

## Technologies Used

- Java
- Object-Oriented Programming
- Console-based user interface
- File handling for saving records
- Collections for managing pet and service data

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/aimadhasan09-ops/Pet-care-Management-System.git
```

### 2. Open the project

Open the project in any Java-supported IDE, such as:

- IntelliJ IDEA
- Eclipse
- NetBeans
- Visual Studio Code

### 3. Compile the program

If Java files are in the current folder, use:

```bash
javac *.java
```

### 4. Run the application

```bash
java Main
```

## How to Use

1. Start the application.
2. Select an option from the main menu.
3. Enter the requested owner, pet, or service details.
4. Use the search and update options to manage pet records.
5. Save the records to a file before exiting.
6. Select option `11` to close the application.

## Project Purpose

The purpose of this project is to provide a simple pet care management system for storing and managing:

- Pet owner information
- Pet profiles
- Vaccination records
- Grooming services
- Boarding services
- Service bookings
- Pet care reports

This project also demonstrates Java programming concepts such as classes, objects, methods, conditional statements, loops, exception handling, and file handling.
