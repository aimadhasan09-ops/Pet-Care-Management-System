# Pet Care Management System

A console-based Pet Care Management System developed using Java.

This application helps manage pet owners, pet profiles, pet services, vaccination details, grooming services, boarding services, and service records through a simple menu-driven interface.

## Features

The application provides the following features:

1. Register Pet Owner
2. Register Pet Profile
3. Book Pet Service
4. Record Vaccination Details
5. Manage Grooming Service
6. Manage Pet Boarding
7. Search Pet Record
8. Update Pet Information
9. Generate Service Report
10. Save Records to File
11. Exit Application

## Technologies Used

- Java
- Java Standard Library
- Console Input and Output
- Object-Oriented Programming
- File Handling

## Feature Description

### Register Pet Owner

This option allows the user to register and store pet owner information.

### Register Pet Profile

This option allows the user to create a profile for a pet.

### Book Pet Service

This option allows the user to book a service for a registered pet.

### Record Vaccination Details

This option allows the user to record vaccination information for a pet.

### Manage Grooming Service

This option allows the user to manage grooming services for pets.

### Manage Pet Boarding

This option allows the user to manage boarding details for pets.

### Search Pet Record

This option allows the user to search for a pet record.

### Update Pet Information

This option allows the user to update existing pet information.

### Generate Service Report

This option allows the user to generate a report containing service details.

### Save Records to File

This option allows the user to save application records to a file.

### Exit Application

This option closes the application.
